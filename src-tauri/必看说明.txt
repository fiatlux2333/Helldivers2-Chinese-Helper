Helldivers 2 中文助手 - 必看说明
================================

一、使用要求

1. 游戏请使用“窗口化”或“无边框窗口”，不要使用独占全屏。
2. 助手和游戏必须保持相同权限级别。优先都普通运行；如果游戏必须管理员运行，助手也必须管理员运行。
3. 首次使用时，先在助手中点击“捕获 HD2”，再按提示切回游戏。
4. 若提示权限不兼容，请关闭游戏和助手后重新打开并对齐权限级别。

二、中文侧栏模式（推荐）

1. 在助手主界面开启“中文侧栏”。
2. 捕获 HD2 后回到游戏，按游戏聊天键唤出右侧输入栏。
3. 选择“直发”会发送原中文；选择“中译英”会先调用翻译接口，再发送英文译文。
4. 使用中文输入法完成候选后按 Enter 发送。
5. 发送或取消后侧栏会自动隐藏，下次按真实聊天键时重新出现。
6. 拖动侧栏左侧手柄可调整位置，位置会自动保存。
7. 助手会在游戏前台保持 CapsLock 游戏态，侧栏输入时临时关闭，降低 HD2 中文输入法卡键风险。

三、主界面模式

1. 在助手主界面关闭“中文侧栏”。
2. 先在游戏中打开聊天框，再点击助手中的“捕获 HD2”。
3. 捕获完成后，在助手中输入文字并选择“中文直发”或“中译英”。
4. 按 Enter 直接发送；按 Ctrl+Enter 只填入游戏聊天框，不自动发送。
5. 当前默认使用 Unicode SendInput 逐字符写入；GBK Alt 数字码已从普通设置中停用。

四、翻译设置

1. 在“设置”中填写 OpenAI 兼容 API 地址、API Key 和模型名。
2. “游戏聊天英译中”和“输入消息中译英”使用独立提示词，可分别修改。
3. 中译英接口失败、译文为空或超过 100 字时，助手不会向游戏发送内容。

五、聊天翻译

1. 捕获 HD2 后进入“聊天翻译”。
2. 首次使用请点击“校准区域”，框选游戏聊天消息区域并保存。
3. 之后可点击“读取并翻译”，或使用截图翻译热键。
4. “设置”里的“英译中结果位置”可选择进入“聊天翻译”页，或留在游戏内透明 HUD 显示最近译文；启用自定义 HUD 位置后可调整水平和垂直位置。
5. 游戏截图只在本机交给 Windows OCR；发送给翻译接口的是识别后的文字。

六、检查更新

1. 软件启动后会检查 GitHub 最新版本；发现新版本时会提示下载。
2. 也可在“设置”中点击“检查更新”。
3. 软件不会自动下载或自动安装更新，只会打开官方 GitHub Release 页面。

七、常见问题

1. 卡输入法或游戏按键异常：先确认“自动 CapsLock 防卡输入法”保持开启；如果仍异常，请切出游戏再切回，或临时切到英文输入法后重试。
2. 无法发送或提示权限不兼容：通常是游戏管理员运行而助手普通运行。请让两边都普通运行，或两边都管理员运行。
3. 取消侧栏输入时，助手会等待 HD2 前台稳定后再发送 Esc；如果仍失败，请导出诊断日志反馈。
