# ✅ 手动验收速查清单

配套 [`windows-probe.md`](windows-probe.md)（T01–T10、F01–F12）。把「记事本 / 误投 / 输入法」三轮映射到代码与判定标准，供真机速查。

> **前置**：先完成 `windows-probe.md` 的系统准备与 A 层逻辑验证。任一项「必测」失败 → 停，先修。

## 🔌 环境判定（本仓库现状）

| 项 | 值 |

## 📝 第一轮：记事本探针（必做）

**目标**：分别验证 `Ctrl+Enter` 只填入和普通 `Enter` 直发。

**准备**

1. 打开记事本 → 另存为 `HELLDIVERS-input-test.txt`
2. 确认标题栏含 `HELLDIVERS`
3. 光标停在编辑区

| 步骤 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- |
| 1 | 点「捕获 HD2」 | 助手最小化；约 4 秒内切回记事本 | ☐ |
| 2 | 助手重新出现 | 提示目标已锁定；`target.valid === true` | ☐ |
| 3 | 输入 `你好，绝地潜兵` 并按 `Ctrl+Enter` | 记事本出现**完整**文字；无自动回车 | ☐ |
| 4 | 重新捕获后按普通 `Enter` | 完整文字后只出现一个回车 | ☐ |

**必测文本**

- [ ] `你好，绝地潜兵`
- [ ] `A点集合，30秒`
- [ ] `测试𠮷字符`（非 BMP，代理对不得拆开）
- [ ] `中文测试🙂继续`
- [ ] `这是一条用于验证多批Unicode输入是否完整的测试消息`

## 🛡 第二轮：误投与失败保护（必做）

依据：`inject_probe_text` 发送前 `restore_foreground` + `validate_foreground`；`injector` 每批再校验，变化即停并置 `partial_prefix_possible`。

- [ ] **A. 填入时切走** → 浏览器**无**文字；助手报目标变化（`TargetChanged`）
- [ ] **B. 捕获后关记事本** → **拒绝发送**，不写别的窗
- [ ] **C. 多批中途切窗** → 中途停止，提示可能已有部分前缀；**不要直接重试整段**
- [ ] **D. 权限不一致**（管理日记事本 + 普通助手）→ 拒绝（`IntegrityIncompatible`）

## ⌨️ 第三轮：输入法

依据：`useCompositionLatch.ts` + `ChatApp.vue` 的 keydown/keyup。

- [ ] **微软拼音**：候选 Enter 不填入；组字结束再 Enter 才填入；候选 Esc 交还 IME；长按不重复；修饰键+Enter 不提交；候选上下键不走历史
- [ ] **搜狗**：同上
- [ ] **微信输入法**：同上

> 单元测试层已由 `useCompositionLatch.test.ts` 覆盖；真机做确认即可。

## 🎮 第四轮：HD2 + 热键（推荐）

- [ ] 窗口化 / 无边框；主界面发送前不需要手动先开聊天框
- [ ] 捕获成功（含 `stingray_window` 进程名回退场景）
- [ ] 普通 Enter 直发成功；`Ctrl+Enter` 仍只填入
- [ ] 无需重捕获即可下一句
- [ ] 填入后助手保持最小化、不抢焦点
- [ ] 开启中文侧栏后，游戏聊天键能唤出输入栏并取得焦点
- [ ] 中文侧栏使用独立 `chat-overlay` 窗口；连续唤出 20 次后主助手尺寸、装饰和位置保持不变
- [ ] 侧栏显示时从任务栏点回主助手，侧栏立即隐藏且主助手正常取得焦点
- [ ] 侧栏可在直发 / 中译英之间切换；中译英失败时保留草稿且不注入
- [ ] 启用侧栏并捕获后，捕获流程自动发 Esc 关闭聊天框；随后从主发言页发送时会重新打开聊天框并写入文字
- [ ] 游戏内按聊天键唤出侧栏后，直接输入 `abc测试`；文字只出现在侧栏输入框，不继续进入游戏聊天框
- [ ] 游戏内按聊天键后不等待，立即连续输入 `abc测试` 20 次；每次开头的 `abc` 和首个中文字符都不丢失
- [ ] 按住聊天键期间侧栏可提前显示但不抢走 HD2 焦点；松开后才取得输入焦点
- [ ] 按住聊天键后切出 HD2 或点回主助手；预热侧栏自动隐藏，松开按键后不会再次弹出
- [ ] 拖动侧栏到新位置后发送并再次唤出，位置保持不变
- [ ] 侧栏刚显示时立即拖到新位置，连续发送并重新唤出 20 次；位置始终保持在最后一次拖动处
- [ ] 侧栏发送或取消后隐藏；下一次真实聊天键能在原位置重新出现
- [ ] 侧栏点击发送后应立即隐藏；快速恢复移动操作时不出现任务栏闪现、输入法锁定或半透明残留
- [ ] 连续发送 20 次后 CapsLock 在 HD2 前台保持保护状态、侧栏前台可输入中文，离开游戏与助手后恢复原始状态
- [ ] 启动旧版本时出现新版本提示；当前版本不误报
- [ ] 设置页“检查更新”能明确显示最新版、可更新或网络失败
- [ ] “下载最新版”只打开官方 GitHub Release 页面，不自动下载安装
- [ ] 安装目录包含 `必看说明.txt`，内容可正常显示中文并覆盖主要使用流程
- [ ] 热键单击唤回；约 0.5s 内连按两次收起
- [ ] 截图翻译热键只读取已校准区域，不触发文字注入
- [ ] 英文 OCR 翻译为中文；中译英接口失败时不填字、不发送
- [ ] 分别在 HDR 开/关及两档游戏聊天背景透明度下框选英文聊天；截图翻译能识别，失败时日志包含 `ocr.failure stage=...` 和截图亮度范围
- [ ] 战备页添加预设后保存；按钮测试可按配置的菜单键和方向序列触发
- [ ] 战备方向输入模式分别选择 WASD / 方向键；与游戏内战备按键设置一致时可成功呼叫
- [ ] 战备全局热键默认不接受主键盘数字或小键盘数字单键
- [ ] 开启“允许数字单键热键”并保存后，主键盘 `1` 和小键盘 `Num1` 可分别录制、显示并触发；关闭后会自动注销这些数字单键热键
- [ ] 战备热键与截图翻译、助手唤回、快捷喊话冲突时不会注册，界面给出冲突提示
- [ ] 关闭助手后 2 秒内任务管理器不再残留助手进程；再次双击不会出现无反应
